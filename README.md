# Digital Clock 

A simple and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**.  
It displays the current time in real-time and updates automatically every second.

## Features

- Displays current time
- Real-time clock update
- Clean and simple UI
- Built with vanilla JavaScript
- Beginner-friendly project
- No external libraries required

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```
Digital-Clock/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository:
```
git clone https://github.com/Vaishnavi10706/Digital-Clock.git
```
2. Open the project folder:
```
cd Digital-Clock
```
3. Open ```index.html``` in your browser.
